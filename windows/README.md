# SUB/WAVE Windows Edition

Windows-обвязка для [SUB/WAVE](https://github.com/perminder-klair/subwave): установка, запуск, остановка, обновление, логи и диагностика без ручной работы в WSL/Ubuntu.

## Что изменено

- запуск непосредственно из Windows через Docker Desktop;
- автоматическое включение WSL 2 и Linux containers;
- установка Docker Desktop через `winget`, когда его нет;
- автоматическая генерация `.env`, логина, пароля и свободного порта;
- рабочие данные хранятся в `%LOCALAPPDATA%\SUBWAVE`, поэтому путь к архиву может быть любым;
- обновление официальных контейнеров одной кнопкой без удаления настроек;
- отдельный диагностический TXT для разбора ошибок;
- скрипт публикации настоящего GitHub-форка в твоём аккаунте.

SUB/WAVE остаётся Linux-контейнерным приложением. Эта версия убирает необходимость вручную устанавливать Ubuntu и вводить Linux-команды, но Docker Desktop всё равно обязателен.

## Быстрый запуск

1. Распакуй архив полностью.
2. Запусти `INSTALL.cmd`.
3. Разреши запрос администратора.
4. Если Windows попросит перезагрузку, перезагрузи ПК и снова запусти `INSTALL.cmd`.
5. После запуска откроется `http://localhost:ПОРТ/onboarding`.

Установщик копирует менеджер в `%LOCALAPPDATA%\SUBWAVE\windows-manager` и создаёт ярлык **SUBWAVE Windows** на рабочем столе и в меню «Пуск». Извлечённый архив после этого не нужен.

## Файлы

- `INSTALL.cmd` — установка или восстановление;
- `START.cmd` / `STOP.cmd` — запуск и остановка;
- `UPDATE.cmd` — обновление compose и официальных образов;
- `OPEN PANEL.cmd` — открыть веб-интерфейс;
- `LOGS.cmd` — живые логи, выход через `Ctrl+C`;
- `DIAGNOSTICS.cmd` — создаёт отчёт в `%LOCALAPPDATA%\SUBWAVE\diagnostics`;
- `PUBLISH FORK TO GITHUB.cmd` — создаёт настоящий форк и ветку `windows-edition` в твоём GitHub.

## Где находятся данные

```text
%LOCALAPPDATA%\SUBWAVE\
├── .env
├── docker-compose.yml
├── state\
├── backups\
└── diagnostics\
```

Удаление распакованного установщика не удаляет радио. Не удаляй `%LOCALAPPDATA%\SUBWAVE\state`, если нужны настройки, голоса, кэш и база.

## Navidrome на том же Windows-компьютере

В мастере SUB/WAVE используй адрес:

```text
http://host.docker.internal:4533
```

а не `http://localhost:4533`, потому что `localhost` внутри контейнера относится к самому контейнеру.

## Требования

- Windows 10 22H2 или Windows 11 x64;
- включённая виртуализация CPU в BIOS/UEFI;
- примерно 8 ГБ RAM минимум, лучше 16 ГБ;
- свободное место для Docker-образов и музыкального анализа.
